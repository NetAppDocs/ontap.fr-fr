= Gérer l'activation automatique d'ONTAP ARP/AI lors des mises à niveau
:toclevels: 1
:allow-uri-read: 
:toclevels: 1
:imagesdir: ../media/


[role="lead"]
Lors de la mise à niveau vers ONTAP 9.18.1 ou une version ultérieure, la protection autonome contre les ransomwares avec intelligence artificielle (ARP/AI) est automatiquement activée par défaut sur tous les nouveaux volumes des systèmes AFF A-series, AFF C-series, ASA et ASA r2 après un délai de grâce de 12 heures, à condition qu'une licence anti-ransomware soit installée. Utilisez cette procédure pour vous désinscrire de l'activation automatique par défaut pendant ou après le délai de grâce, ou pour modifier ce paramètre à tout moment après la mise à niveau.


NOTE: Si vous utilisez ONTAP 9.15.1 ou une version antérieure, consultez link:index.html["Découvrez la protection autonome contre les ransomwares"].


NOTE: Si vous utilisez ONTAP 9.17.1 ou une version antérieure, l'activation automatique par défaut au niveau du cluster ne s'applique pas. Vous pouvez configurer l'activation par défaut au niveau de la SVM à l'aide de link:enable-default-arpai.html["Activer ARP/AI par défaut dans les nouveaux volumes"].


NOTE: Les volumes existants doivent être link:enable-arpai.html["activé manuellement"] pour ARP/AI.


NOTE: À partir d'ONTAP 9.19.1, l'activation par défaut d'ARP/AI s'applique aux clusters qui incluent des relations SnapMirror synchrones et SnapMirror active sync SAN. Dans ONTAP 9.18.1, l'activation par défaut était supprimée pour ces configurations. Pour les relations SnapMirror synchrones inter-clusters, l'activation par défaut est effective après la mise à niveau des clusters source et de destination vers ONTAP 9.19.1.

.Description de la tâche
Le paramètre que vous choisissez peut être modifié ultérieurement. Après le délai de grâce, vous avez toujours la possibilité d’activer ou de désactiver l’activation automatique par défaut à tout moment :

[source, cli]
----
security anti-ransomware auto-enable modify -new-volume-auto-enable false|true
----
.Étapes
Vous pouvez utiliser System Manager ou l'interface de ligne de commande ONTAP pour gérer l'activation automatique par défaut d'ARP/AI.

[role="tabbed-block"]
====
.System Manager
--
. Sélectionnez *Cluster > Paramètres*.
. Effectuez l'une des opérations suivantes :
+
** Désactiver pendant le délai de grâce :
+
... Dans la section *Anti-ransomware*, un message vous indiquera le nombre d'heures restantes avant l'activation d'ARP/AI. Sélectionnez *Ne pas activer*.
... Sélectionnez *Désactiver* dans la boîte de dialogue suivante pour confirmer que l'activation par défaut d'ARP/AI est désactivée pour les nouveaux volumes.


** Désactiver après délai de grâce :
+
... Dans la section *Anti-ransomware*, sélectionnez image:icon_pencil.gif["Icône Modifier"].
... Cochez la case puis cliquez sur *Enregistrer* pour désactiver l'activation automatique par défaut d'ARP/AI pour les nouveaux volumes.






--
.CLI
--
. Vérifiez l'état de l'activation automatique :
+
[source, cli]
----
security anti-ransomware auto-enable show
----
. Désactivez l’activation automatique par défaut pour les nouveaux volumes :
+
[source, cli]
----
security anti-ransomware auto-enable modify -new-volume-auto-enable false
----
