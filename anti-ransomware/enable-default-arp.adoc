= Activer ONTAP ARP par défaut dans les nouveaux volumes
:hardbreaks:
:toclevels: 1
:allow-uri-read: 
:toclevels: 1
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
À partir d'ONTAP 9.10.1, vous pouvez configurer les machines virtuelles de stockage (SVM) afin que les nouveaux volumes NAS soient activés par défaut avec la protection autonome contre les ransomwares (ARP) en mode d'apprentissage. Vous pouvez modifier ce paramètre à l'aide de System Manager ou de l'interface de ligne de commande ONTAP.


NOTE: Si vous utilisez ONTAP 9.16.1 ou une version ultérieure, consultez link:enable-default-arpai.html["Activer ARP/AI par défaut dans les nouveaux volumes"].


NOTE: Pour ONTAP 9.13.1 à 9.17.1, les volumes FlexGroup utilisent l'ancien modèle ARP et nécessitent une période d'apprentissage. Utilisez cette procédure pour les volumes FlexGroup exécutant ONTAP 9.17.1 et versions antérieures.

.Description de la tâche
Par défaut, les nouveaux volumes sont créés avec ARP désactivé. Lorsque vous activez ARP par défaut sur une SVM, les nouveaux volumes créés dans cette SVM démarrent automatiquement en mode d'apprentissage ARP (`dry-run`. Les volumes existants sans ARP activé ne verront pas leur état d'activation ARP modifié lorsque vous changez la valeur par défaut de la SVM.

À partir d'ONTAP 9.13.1, l'apprentissage adaptatif est activé par défaut, ce qui signifie qu'ARP bascule automatiquement du mode d'apprentissage au mode actif une fois la période d'apprentissage jugée suffisante. Vous pouvez désactiver ce basculement automatique pour contrôler manuellement la transition.

[[arp-enablement-default-behavior-table]]
Après avoir activé la protection autonome contre les ransomwares, une période de transition peut commencer en fonction de votre environnement et de votre version d'ONTAP :

[cols="25,25,50"]
|===
| Type de volume | Version ONTAP | Comportement après activation 


.2+| NAS FlexGroup | ONTAP 9.18.1 et versions ultérieures | ARP/AI est immédiatement actif, sans période d'apprentissage. 


| ONTAP 9.13.1 à 9.17.1 | ARP démarre en mode apprentissage pendant 30 jours 


.2+| NAS FlexVol | ONTAP 9.16.1 et versions ultérieures | ARP/AI est immédiatement actif, sans période d'apprentissage. 


| ONTAP 9.10.1 à 9.15.1 | ARP démarre en mode apprentissage pendant 30 jours 


| Volumes SAN | ONTAP 9.17.1 et versions ultérieures | Le système ARP/AI est immédiatement actif, lançant une période d'évaluation pour établir un seuil d'alerte approprié avant de passer d'un seuil initial conservateur. 
|===
.Avant de commencer
* Une machine virtuelle de stockage (SVM) avec le protocole NFS ou SMB (ou les deux) activé.
* Un actiflink:../concepts/namespaces-junction-points-concept.html["chemin de jonction"] pour le volume.
* Le link:index.html#licenses-for-autonomous-ransomware-protection["licence correcte"] pour votre version ONTAP.
* (Recommandé) Vérification multi-administrateur (MAV) activée (ONTAP 9.13.1 et versions ultérieures). Voirlink:../multi-admin-verify/enable-disable-task.html["Activez la vérification multiadministrateur"] .


.Étapes
Vous pouvez utiliser System Manager ou l'interface de ligne de commande ONTAP pour activer ARP par défaut pour les nouveaux volumes au niveau SVM.

[role="tabbed-block"]
====
.System Manager
--
. Sélectionnez *Storage VMs*, puis sélectionnez la Storage VM qui contiendra les volumes que vous souhaitez protéger avec ARP.
. Accédez à l'onglet *Paramètres*. Sous *Sécurité*, localisez la vignette *Anti-ransomware*, puis sélectionnez image:icon_pencil.gif["Icône Modifier"] .
. Cochez la case pour activer l'anti-ransomware (ARP). Cochez la case supplémentaire pour activer ARP sur tous les volumes éligibles de la machine virtuelle de stockage.
. Sélectionnez *Passer automatiquement du mode d'apprentissage au mode actif après un apprentissage suffisant* pour permettre à ARP de déterminer la période d'apprentissage optimale et d'automatiser le passage au mode actif (ONTAP 9.13.1 et versions ultérieures).


--
.CLI
--
*Modifier une SVM existante pour activer ARP par défaut en mode d'apprentissage pour les nouveaux volumes :*

[source, cli]
----
vserver modify -vserver <svm_name> -anti-ransomware-default-volume-state dry-run
----
*Créer une nouvelle SVM avec ARP activé par défaut (en mode d'apprentissage) pour les nouveaux volumes :*

[source, cli]
----
vserver create -vserver <svm_name> -anti-ransomware-default-volume-state dry-run
----
*Désactivez la transition automatique vers le mode actif (optionnel) :*

Si vous utilisez ONTAP 9.13.1 à 9.15.1 et souhaitez contrôler manuellement le passage du mode d'apprentissage au mode actif pour tous les volumes associés au SVM :

[source, cli]
----
vserver modify -vserver <svm_name> -anti-ransomware-auto-switch-from-learning-to-enabled false
----
*Vérifier l'état ARP :*

[source, cli]
----
security anti-ransomware volume show
----
--
