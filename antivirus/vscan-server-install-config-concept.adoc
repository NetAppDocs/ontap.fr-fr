= Installation et configuration du serveur ONTAP Vscan
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Configurez un ou plusieurs serveurs Vscan pour vous assurer que les fichiers de votre système sont analysés pour détecter d'éventuels virus. Suivez les instructions fournies par votre fournisseur pour installer et configurer le logiciel antivirus sur le serveur.

Suivez les instructions du fichier README fourni par NetApp pour installer et configurer ONTAP Antivirus Connector. Vous pouvez également suivre les instructions link:install-ontap-antivirus-connector-task.html["Installez la page ONTAP antivirus Connector"].

[NOTE]
====
Pour les configurations de reprise après incident et MetroCluster, vous devez installer et configurer des serveurs Vscan distincts pour les clusters ONTAP principal/local et secondaire/partenaire.

====


[[antivirus-software-requirements]]
== Configuration logicielle requise pour l'antivirus

* Pour plus d'informations sur la configuration requise pour le logiciel antivirus, reportez-vous à la documentation du fournisseur.
* Pour plus d'informations sur les fournisseurs, les logiciels et les versions pris en charge par Vscan, consultez link:../antivirus/vscan-partner-solutions.html["Solutions partenaires Vscan"].




[[ontap-antivirus-connector-requirements]]
== Conditions requises pour ONTAP antivirus Connector

Chaque SVM utilise soit ICAP, soit Antivirus Connector, mais pas les deux.

* Vous pouvez télécharger ONTAP Antivirus Connector depuis la page link:http://mysupport.netapp.com/NOW/cgi-bin/software["Téléchargement de logiciels"^] sur le site de support NetApp.
* Pour plus d'informations sur les versions de Windows prises en charge par le connecteur antivirus ONTAP et sur les conditions d'interopérabilité, voir link:../antivirus/vscan-partner-solutions.html["Solutions partenaires Vscan"].
+
[NOTE]
====
Vous pouvez installer différentes versions de serveurs Windows pour différents serveurs Vscan dans un cluster.

====
* .NET 3.0 ou version ultérieure doit être installé sur le serveur Windows.
* SMB 2.0 doit être activé sur le serveur Windows.




[[icap-capable-scan-engine-requirements]]
== Exigences relatives aux moteurs d’analyse compatibles ICAP

Chaque SVM utilise soit ICAP, soit Antivirus Connector, mais pas les deux.

* À partir d'ONTAP 9.20.1, ONTAP prend en charge un chemin d'analyse basé sur ICAP qui élimine le besoin d'Antivirus Connector.
* ICAP prend en charge les moteurs d'analyse basés sur Linux et ne nécessite pas Windows, .NET ou SMB 2.0.



NOTE: Si vous revenez d'ONTAP 9.20.1 à une version antérieure, vous devez d'abord supprimer toutes les configurations ICAP.

En savoir plus sur link:icap-vscan.html["Configurations Vscan basées sur ICAP"].
