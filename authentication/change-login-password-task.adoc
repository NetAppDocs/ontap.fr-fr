= Modifier le mot de passe d'un administrateur ONTAP
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Vous devez modifier votre mot de passe d'administrateur ONTAP initial immédiatement après votre première connexion, puis périodiquement, afin de préserver la sécurité de votre cluster.

À partir d'ONTAP 9.20.1, si votre compte utilisateur est configuré pour recevoir des alertes d'expiration de mot de passe, System Manager affiche une bannière d'alerte à partir de 14 jours avant l'expiration de votre mot de passe. Cette alerte se met à jour à chaque connexion pour indiquer le nombre de jours restants.

.Description de la tâche
Le nouveau mot de passe doit respecter les règles suivantes :

* Il ne peut pas contenir le nom d'utilisateur
* Elle doit comporter au moins huit caractères
* Il doit contenir au moins une lettre et un chiffre
* Il ne peut pas être le même que les six derniers mots de passe



NOTE: Vous pouvez utiliser `security login role config modify` la commande pour modifier les règles relatives aux mots de passe pour les comptes associés à un rôle donné.

.Avant de commencer
* Vous devez être un administrateur de cluster ou de SVM pour modifier votre propre mot de passe.
* Vous devez être un administrateur de cluster pour modifier le mot de passe d'un autre administrateur.


.Étapes
Utilisez System Manager ou l'interface de ligne de commandes ONTAP (CLI) pour modifier votre mot de passe.

[role="tabbed-block"]
====
.System Manager
--
. Dans System Manager, sélectionnez *Cluster > Paramètres*.
. Sous *Utilisateurs et rôles*, sélectionnez *Utilisateurs*.
. Sélectionnez image:icon_kabob.gif["Menu"] en regard du compte utilisateur dont vous devez modifier le mot de passe, puis sélectionnez *Modifier le mot de passe*.
. Saisissez le nouveau mot de passe.
. Saisissez à nouveau le nouveau mot de passe pour le confirmer, puis sélectionnez *Enregistrer*.


--
.CLI
--
Si vous êtes administrateur SVM, vous pouvez utiliser la  `security login password`commande pour modifier votre propre mot de passe. Si vous êtes administrateur du cluster, vous pouvez utiliser la  `security login password`commande pour modifier le mot de passe de n'importe quel administrateur.

. Modifier un mot de passe d'administrateur : `security login password -vserver _svm_name_ -username _user_name_`
+
La commande suivante modifie le mot de passe de l’administrateur `admin1` pour le SVM `vs1.example.com`. Vous êtes invité à saisir le mot de passe actuel, puis à saisir et à confirmer le nouveau mot de passe.

+
[listing]
----
vs1.example.com::>security login password -vserver engData -username admin1
Please enter your current password:
Please enter a new password:
Please enter it again:
----
