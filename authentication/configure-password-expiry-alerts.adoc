= Configurer les alertes d'expiration des mots de passe des utilisateurs ONTAP dans System Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
À partir d'ONTAP 9.20.1, si le rôle associé à un compte utilisateur est configuré pour les alertes d'expiration de mot de passe, l'utilisateur reçoit une bannière d'alerte en haut de la page dans System Manager immédiatement après sa connexion, à partir de 14 jours avant l'expiration du mot de passe. Cette alerte est mise à jour chaque fois que l'utilisateur se connecte pour indiquer le nombre de jours restants avant l'expiration du mot de passe. Vous pouvez configurer les alertes d'expiration lorsque vous ajoutez ou modifiez un rôle d'administrateur.

.Étapes
. Sélectionnez *Cluster > Paramètres*.
. Sélectionnez image:icon_arrow.gif["icône de flèche"] à côté de *Users and roles*.
. Configurez les alertes d'expiration de mot de passe lors de l'ajout ou de la modification d'un rôle d'utilisateur.
+
** Pour configurer lors de l’ajout d’un rôle utilisateur, sous *Rôles*, sélectionnez image:icon_add.gif["ajouter une icône"]. Saisissez un nom pour le rôle, puis sélectionnez la période d’expiration du mot de passe et une alerte d’expiration du mot de passe.
** Pour configurer un rôle utilisateur lors de sa modification, sous *Rôles*, sélectionnez le rôle utilisateur. Sélectionnez *Modifier*, puis sélectionnez la période d'expiration du mot de passe.
** Sélectionnez *Ajouter*.




.Résultat
L'utilisateur reçoit une bannière d'alerte en haut de la page dans System Manager immédiatement après s'être connecté, à partir du nombre de jours sélectionné avant l'expiration du mot de passe. L'alerte se met à jour chaque fois que l'utilisateur se connecte afin d'afficher le nombre de jours restants avant l'expiration du mot de passe.
