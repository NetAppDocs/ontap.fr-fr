= Calculez l'espace récupérable avant de supprimer les snapshots ONTAP
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Vous pouvez sélectionner les instantanés que vous souhaitez supprimer et calculer l'espace récupérable avant de les supprimer.

Dans les versions antérieures à ONTAP 9.20.1, le calcul de l'espace récupérable est pris en charge pour les volumes FlexVol, et pour les volumes FlexGroup, il nécessite de combiner manuellement l'utilisation des snapshots sur les volumes constitutifs FlexGroup. À partir d'ONTAP 9.20.1, vous pouvez calculer l'espace récupérable pour les snapshots dans les volumes FlexGroup.

.Étapes
Vous pouvez effectuer cette tâche depuis System Manager ou l'interface de ligne de commandes de ONTAP.

[role="tabbed-block"]
====
.System Manager
--
. Cliquez sur *Storage > volumes*.
. Sélectionnez le volume à partir duquel vous souhaitez supprimer des snapshots.
. Cliquez sur *Instantanés*.
. Sélectionnez un ou plusieurs instantanés.
. Cliquez sur *calculer l'espace de récupération*.


--
.CLI
--
. Calculer l'espace récupérable :
+
`volume snapshot compute-reclaimable -vserver <svm_name> -volume <volume_name> -snapshots <snap1,snap2,snap3>`
