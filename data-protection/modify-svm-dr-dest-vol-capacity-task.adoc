= Modifier la capacité du volume de destination dans une relation de reprise après sinistre de SVM ONTAP
:hardbreaks:
:toclevels: 1
:allow-uri-read: 
:toclevels: 1
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
À partir d'ONTAP 9.20.1, les administrateurs du stockage et de la protection des données peuvent ajuster certains attributs de capacité de volume sur un volume de destination SVM DR afin de maintenir les limites de dimensionnement automatique de la destination alignées sur la croissance de la source, d'augmenter la réserve de snapshots pour la conservation de la destination, et les administrateurs de fournisseurs de services peuvent gérer avec précision les clients DR multilocataires en fonction de la capacité de la destination.



[[adjust-the-maximum-size-svm-dr-destination-volumes-can-grow-automatically]]
== Ajustez la taille maximale que les volumes de destination SVM DR peuvent atteindre automatiquement

.Étapes
. Pour modifier la valeur maximale de dimensionnement automatique du volume, saisissez la commande suivante :
+
`volume modify -vserver <dest svm name> -volume <vol name> -max-autosize <integer>`

+
Exemple :

+
[listing]
----
volume modify -vserver svmdr_dst -volume vol1 -max-autosize 10TB
----




[[adjust-the-minimum-size-svm-dr-volumes-can-shrink-automatically]]
== Ajustez la taille minimale à laquelle les volumes SVM DR peuvent se réduire automatiquement

. Pour modifier la valeur minimale de dimensionnement automatique d'un volume, saisissez la commande suivante :
+
`volume modify -vserver <dest svm name> -volume vol1 -min-autosize <integer>`

+
Exemple :

+
[listing]
----
volume modify -vserver svmdr_dst -volume vol1 -min-autosize 1TB
----




[[change-the-volumes-autosize-mode]]
== Modifier le mode de dimensionnement automatique du volume

. Pour modifier le mode de redimensionnement automatique, saisissez la commande suivante :
+
`volume modify -vserver svmdr_dst -volume vol1 -autosize-mode`

+
Exemple :

+
[listing]
----
volume modify -vserver svmdr_dst -volume vol1 -autosize-mode grow
----




[[adjust-the-amount-of-space-reserved-for-snapshots]]
== Ajustez l'espace réservé aux instantanés

. Pour modifier le pourcentage d'espace réservé aux instantanés, saisissez la commande suivante :
+
`volume modify -vserver <dest svm name> -volume <vol name> -percent-snapshot-space <integer>`

+
Exemple :

+
[listing]
----
volume modify -vserver svmdr_dst -volume vol1 -percent-snapshot-space 25
----
