= Déposer un miroir ONTAP FabricPool
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Si vous n'avez plus besoin de répliquer un magasin d'objets, vous pouvez supprimer un miroir FabricPool.

.Avant de commencer
Le magasin d'objets principal doit être opérationnel ; sinon, la commande échoue.


WARNING: Cette opération supprime définitivement tous les objets du conteneur de stockage d'objets et est irréversible. La suppression des objets se poursuit en arrière-plan une fois l'opération de suppression du miroir terminée. Ne réutilisez pas le conteneur et ne le réaffectez pas tant que le processus de suppression en arrière-plan n'est pas terminé.

.Étape
. Supprimez un miroir de magasin d'objets dans un FabricPool à l'aide de `storage aggregate object-store unmirror -aggregate` commande.
+
[listing]
----
cluster1::> storage aggregate object-store unmirror -aggregate aggr1
----
