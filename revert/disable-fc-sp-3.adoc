= Désactivez FC-SP-3 sur les LIF FC avant de revenir à une version antérieure à ONTAP 9.20.1
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
À partir de ONTAP 9.20.1, ONTAP prend en charge le protocole d'authentification et le chiffrement Fibre Channel Security Protocol 3 (FC-SP-3) à l'aide d'adaptateurs de bus hôte (HBA) sécurisés Broadcom avec les systèmes AFF et FAS. Si des interfaces réseau FC ou NVMe/FC (LIF) sont activées pour FC-SP-3 sur votre système ONTAP, vous devez les désactiver avant de revenir à ONTAP 9.19.1.

.Étapes
. Vérifiez la configuration FC-SP-3 sur vos LIF :
+
[source, cli]
----
network interface show -fields fc-transport-security
----
. Si le statut du champ *transport-security-state* n'est pas disponible, aucune action supplémentaire n'est requise. Si le statut est *mandatory* ou *preferred*, modifiez-le en *disabled*:
+
[source, cli]
----
network interface modify -vserver <vserver_name> -lif <lif_name> -fc-transport-security disabled
----
. Vérifiez que FC-SP-3 est désactivé sur les LIF précédemment activées :
+
[source, cli]
----
network interface show -fields fc-transport-security
----
