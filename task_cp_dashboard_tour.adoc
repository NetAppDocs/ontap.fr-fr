= Consultez les informations du cluster à partir du tableau de bord ONTAP System Manager
:hardbreaks:
:toclevels: 1
:allow-uri-read: 
:toclevels: 1
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Le tableau de bord de System Manager offre une vue rapide et complète de votre cluster ONTAP à partir d'un emplacement unique.

Depuis le tableau de bord de System Manager, vous pouvez consulter des informations sur l’état, la capacité, le réseau et les performances de votre cluster, notamment les alertes importantes, l’efficacité et la capacité des niveaux et volumes de stockage, l’état et la disponibilité des nœuds du cluster, les applications et objets les plus actifs, ainsi que les indicateurs de performance.

À partir d'ONTAP 9.19.1, les administrateurs SVM peuvent surveiller et gérer leurs propres SVM à l'aide d'un tableau de bord administrateur SVM dédié dans ONTAP System Manager. Pour plus d'informations, consultez link:task-svm-admin-dashboard-sm.html["Gérez et surveillez les SVM avec System Manager"].

Le tableau de bord comprend quatre panneaux décrits comme suit :



[[view-the-cluster-health]]
== Consulter l'état du cluster

Dans la section *État* du tableau de bord ONTAP System Manager, vous pouvez consulter des informations générales sur votre cluster, telles que son nom, sa version d'ONTAP et sa date de création. Vous pouvez également consulter l'état général des nœuds de votre cluster, les erreurs, avertissements et alertes au niveau du cluster, ainsi que les modifications suggérées pour améliorer les performances du cluster.

À partir d'ONTAP 9.20.1, une alerte de santé s'affiche 30 jours avant l'expiration d'un certificat de cluster ou de machine virtuelle de stockage (SVM). Cette alerte est mise à jour quotidiennement pour indiquer le nombre de jours restants avant l'expiration. Vous pouvez modifier le seuil d'alerte par défaut de 30 jours pour le définir sur un nombre de jours compris entre 0 et 90, le désactiver afin qu'aucune alerte ne soit affichée, ou encore supprimer les alertes pour les certificats déjà expirés tout en continuant à recevoir des alertes pour les expirations à venir.

* Pour consulter les informations sur l'état du cluster, sélectionnez image:icon_arrow.gif["Icône de flèche"] à côté de *Santé* sur le tableau de bord.
* Pour modifier les paramètres d'expiration du certificat, sélectionnez l'alerte, puis sélectionnez *Certificate Settings*.




[[view-the-cluster-capacity]]
== Afficher la capacité du cluster

Dans la section *Capacité* du tableau de bord ONTAP System Manager, vous pouvez afficher l'espace de stockage d'un cluster. Vous pouvez afficher l'espace logique total utilisé, l'espace physique total utilisé et l'espace disque disponible.

Vous pouvez choisir de vous inscrire à ActiveIQ pour consulter les données historiques du cluster.

Sélectionnez l’option image:icon_arrow.gif["Icône de flèche"] à côté de *Capacité* sur le tableau de bord pour afficher les informations de capacité du cluster, notamment un aperçu des niveaux associés à un cluster, tels que l’espace total, l’espace utilisé et l’espace disponible. Les détails relatifs au débit, aux IOPS et à la latence sont également affichés. link:./concepts/capacity-measurements.html["Découvrez comment ONTAP indique le stockage utilisé"].

Vous pouvez choisir d'ajouter un Tier local ou un Tier cloud à l'aide de la vue capacité. Pour plus d'informations, reportez-vous link:task_admin_monitor_capacity_in_sm.html["Afficher la capacité d'un cluster"]à .



[[view-the-cluster-network]]
== Afficher le réseau du cluster

Dans la section *Réseau* du tableau de bord ONTAP System Manager, vous pouvez afficher les ports physiques, les interfaces réseau et les VM de stockage qui font partie du réseau.

La vue réseau affiche le type de clients connectés au réseau. Chacun de ces clients connectés au réseau est représenté par un chiffre (par exemple, « NVMe/FC 16 »). Sélectionnez le numéro pour afficher des détails spécifiques sur chacun de ces éléments réseau.

Sélectionnez l’option image:icon_arrow.gif["Icône de flèche"] à côté de *Réseau* sur le tableau de bord pour afficher une vue complète du réseau, incluant les ports, les interfaces réseau, les machines virtuelles de stockage et les hôtes du réseau.



[[view-the-cluster-performance]]
== Afficher les performances du cluster

Dans la section *Performance* du tableau de bord ONTAP System Manager, vous pouvez consulter des statistiques de performance pour vous aider à surveiller l'état et l'efficacité de votre cluster ONTAP. Ces statistiques incluent des indicateurs clés de performance du cluster, tels que la latence, le débit et les IOPS, représentés sous forme de graphiques.

La vue performances affiche les statistiques de performances à différents intervalles de temps par jour, heure, semaine ou année. Vous pouvez rapidement analyser les performances du cluster à l'aide des différents graphiques et identifier les caractéristiques susceptibles de nécessiter une optimisation. Cette analyse rapide vous aide à décider comment ajouter ou déplacer des charges de travail. Vous pouvez également examiner les heures de pointe pour planifier les changements potentiels.

La vue des performances affiche les mesures de performances totales liées à la latence, au débit et aux IOPS.

Depuis la version 9.15.1, l'affichage des performances est amélioré et affiche des graphiques pour les mesures de performance en lecture, écriture, autre et totale liées à la latence, au débit et aux IOPS. Les autres indicateurs incluent les opérations qui ne sont pas lues ou écrites.

Les valeurs de performance sont renouvelées toutes les 3 secondes et le graphique de performances est actualisé toutes les 15 secondes. Un graphique ne s'affiche pas si les informations relatives aux performances du cluster ne sont pas disponibles.

Sélectionnez image:icon-expansion-arrows.png["Icône d'expansion"] à côté de *Performance* sur le tableau de bord pour afficher une vue en page complète des indicateurs de performance par heure, jour, semaine, mois et année. Vous pouvez également télécharger un rapport des indicateurs de performance sur votre système local.
