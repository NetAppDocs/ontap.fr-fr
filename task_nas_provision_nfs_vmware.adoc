= Provisionnez le stockage NFS pour les banques de données VMware avec ONTAP System Manager
:hardbreaks:
:toclevels: 1
:allow-uri-read: 
:toclevels: 1
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Avant d'utiliser ONTAP tools for VMware vSphere pour provisionner des volumes NFS sur un système de stockage basé sur ONTAP pour les hôtes ESXi, activez NFS à l'aide de System Manager pour ONTAP 9.7 ou version ultérieure.

Après avoir créé un link:task_nas_enable_linux_nfs.html["Machine virtuelle de stockage compatible NFS"] dans System Manager, vous provisionnez ensuite des volumes NFS et gérez les datastores à l'aide des ONTAP tools for VMware vSphere.

Assurez-vous de vérifier le  https://imt.netapp.com/matrix/["Matrice d'interopérabilité NetApp"^] pour confirmer la compatibilité entre votre version actuelle d'ONTAP et ONTAP tools for VMware vSphere.

Pour configurer l'accès NFS des hôtes ESXi aux banques de données à l'aide de System Manager Classic (pour ONTAP 9.7 et versions antérieures), consultez https://docs.netapp.com/us-en/ontap-system-manager-classic/nfs-config-esxi/index.html["Vue d'ensemble de la configuration NFS pour ESXi"^]

Pour plus d'informations, consultez  https://docs.netapp.com/us-en/netapp-solutions/virtualization/vsphere_ontap_ontap_for_vsphere.html["Tr-4597 : VMware vSphere pour ONTAP"^] et le  https://docs.netapp.com/us-en/ontap-tools-vmware-vsphere-10/["Documentation sur les outils ONTAP pour VMware vSphere"^].
