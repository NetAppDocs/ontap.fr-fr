= Flux de travail de vérification post-mise à niveau ONTAP
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Après la mise à niveau de ONTAP, vous devez effectuer plusieurs tâches pour vérifier que le cluster est prêt.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["Une seule"]Vérifiez votre cluster.
[role="quick-margin-para"]
Après la mise à niveau de ONTAP, vous devez link:task_verify_cluster_after_upgrade.html["Vérifiez la version de votre cluster, l'état du cluster et l'état du stockage"]. Si vous utilisez une configuration MetroCluster FC, vous devez également vérifier que le cluster est activé pour le basculement automatique non planifié.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png["Deux"]Vérifiez que toutes les interfaces logiques (LIF) sont sur les ports d'origine.
[role="quick-margin-para"]
Lors d'un redémarrage, certaines interfaces logiques (LIF) peuvent avoir été migrées vers leurs ports de basculement respectifs. Après la mise à niveau d'un cluster, vous devez link:task_enabling_and_reverting_lifs_to_home_ports_post_upgrade.html["activer et rétablir les LIF qui ne sont pas sur leurs ports d'origine"].

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png["Trois"]Vérifiez les considérations particulières propres à votre cluster.
[role="quick-margin-para"]
Si certaines configurations existent sur votre cluster, vous pourriez avoir besoin de link:concept_special_configurations_post_checks.html["Effectuez des étapes supplémentaires après la mise à niveau"].

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-4.png["Quatre"]Mettre à jour le Disk Qualification Package (DQP).
[role="quick-margin-para"]
Le DQP n'est pas mis à jour lors d'une mise à niveau d'ONTAP. Vous devez link:concept_when_you_need_to_update_the_disk_qualification_package.html["mettre à jour le DQP"] après la mise à niveau.
